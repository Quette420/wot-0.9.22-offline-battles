# v1.2.1 - Testing tab defaults

## Bug fixes

Cleared the default selections for player automatic control and logging on the launcher's Testing tab. On first launch and after reopening the launcher following a factory reset, all four player automatic control checkboxes and both logging checkboxes are unchecked, including **Collect detailed diagnostic logs**. Upgrading retains your saved selections.

## How to use the Testing tab

Use the launcher's Testing tab to collect diagnostic logs, choose a single-player test scene, or set up player automatic control. Changes apply the next time you launch the game.

- **Collect detailed diagnostic logs** — Records more detail about game operation and combat to help diagnose target selection, aiming, and firing issues.
- **Collect detailed collision logs** — Records collision checks and contacts to help diagnose vehicles blocking one another, scraping, or getting stuck.
- **Automatic driving** — Takes over vehicle movement and hull steering.
- **Automatic aiming and fire** — Takes over target selection, target lock, aiming, and firing.
- **Automatic consumables** — Uses equipped consumables such as repair kits, first aid kits, and fire extinguishers as needed.
- **Start automatic control at battle start** — Takes over the selected features as soon as the battle is ready. Features you leave unchecked stay under manual control.

Use **Test scene** to select a normal single-player battle or a dedicated test scene, then use the regular Start button. Use **Open player control panel** to send test commands such as starting takeover, returning to manual control, or stopping the vehicle.

### Turning player automatic control on and off in battle

1. Before launching the game, select **Start automatic control at battle start** and at least one automatic control feature on the Testing tab.
2. The selected features take over when the battle is ready. In the battle controls, press the **backtick key** (`` ` ``) immediately to the left of **1** on the main keyboard's number row to turn automatic control off and return to manual control.
3. Press the same key again to turn the selected automatic control features back on.
